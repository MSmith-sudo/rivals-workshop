## Live checks and limits

One real YouTube oEmbed call for a public sample returned its genuine platform title, uploader and `i.ytimg.com` thumbnail URL. No player data or API key was involved. Metadata/image availability remains subject to YouTube restrictions and connectivity; fallback retains user credits and external links.

Gemini/OpenRouter/OpenAI response paths were tested with mocked transports. No real Gemini key was supplied in this ZIP, so the new prompts were not quality-tested against a live model. The user's existing working Gemini adapter and environment-variable contract are preserved. AI factual fidelity relies on constrained prompts plus player review; schema and citation checks cannot semantically prove every generated sentence.

`node scripts/ui-fixture.mjs` optionally runs an isolated mock UI server at port 8792 for repeatable manual checks. It uses no external provider or real credentials; outputs are visibly marked TEST. Use `npm run server` for normal operation.
