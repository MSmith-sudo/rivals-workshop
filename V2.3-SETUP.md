# Rivals Workshop 2.3 — run and upgrade

This is an upgrade of the supplied v2.2 React/Vite project. All seven chapters, local rules, first-attempt/rehearsal distinction, Gemini backend, Player Vault migrations, Chemistry Lab and soundtrack metadata remain in place.

## Before upgrading

In the original app, save the active chapters into a Player Vault profile and export the library JSON. Export any chapter-specific backup you need. Browser saves belong to an origin (host and port): keep using the same origin to see existing progress automatically. Moving from development port 5173 to production port 8787 requires exporting/importing profiles. Opening a different folder does not itself move browser data.

## Requirements and first run

Use Node.js 22.9 or newer (Node 24 is suitable). Unzip the folder, open a terminal inside `rivals-workshop`, and run:

```powershell
npm ci
npm test
npm run build
Copy-Item .env.server.example .env.server
```

The ZIP contains a built `dist` folder, full source, tests and the server. Dependencies are installed with `npm ci`; they are not bundled. The app can run offline after installation; optional AI requires a configured provider and network access.

## Optional Gemini

Edit `.env.server` locally. Keep the key out of client files, screenshots and exports. Do not use a `VITE_` variable for any secret.

```dotenv
AI_PROVIDER=gemini
AI_MODEL=gemini-2.5-flash-lite
GEMINI_API_KEY=your_key_here
AI_API_KEY=
AI_BASE_URL=
PORT=8787
APP_ORIGIN=http://127.0.0.1:8787
```

The model name is the existing configurable project default, not a promise of current availability or quota. If your account cannot use it, set `AI_MODEL` to an available Gemini model. Leave `AI_PROVIDER=offline` to use the authored local reflections without AI. Restart the backend after environment changes.

```powershell
npm run server
```

Open **http://127.0.0.1:8787**. For development, use `APP_ORIGIN=http://127.0.0.1:5173`, start the backend in one terminal and `npm run dev` in another. The development proxy expects backend port 8787. Use the same hostname as before; localhost and 127.0.0.1 have different browser saves.

## Using the story studio

Chapters 1–6 have “Reflect on my saved chapter answers” in their banner; close/reopen it to refresh after answering. Chapter 7’s integrated dossier, saved Player Vault profiles and consenting teams have a full narrative studio. Original field-level writing help remains available.

Local reflection is ready without transmitting answers. To use AI, open the optional drafting controls, select chapters, review the exact payload and consent to that request. Read and edit the preview, then accept or discard it. Regeneration requires fresh consent. Generated text is visibly labeled, rendered as plain text, and cannot alter scores. Citations reference the saved evidence preview; interpretations still need your review. An accepted edited AI draft is labeled player-edited.

Narratives save separately from chapter schemas so existing migrations remain intact. Export/import narrative JSON using the story studio controls; imports are unsaved drafts until accepted. Narrative exports deliberately omit receipts. Player Vault exports continue to contain chapter snapshots and creative titles; export the narrative separately when transferring your story. Text itself may still contain personal details. No automatic sharing is added. Team analysis continues to require every member’s local consent; provider transmission requires separate request consent.

## Artwork

See `ASSET-RIGHTS.md`. Original role emblems and illustrated role mascots are the default fallback, not depictions of named Marvel heroes. Add portraits you have permission to use through `src/hero-media.json`. The supplied splash bitmap remains in the project, unused by default, without a license claim. Rebuild after changing media. No arbitrary artwork is hotlinked.

## Errors and recovery

Missing backend/configuration: use local reflection or start the server. Provider quota/429: wait for the displayed interval; the app does not automatically retry. Network, malformed reply or invalid evidence citations: no draft is accepted and existing saves remain intact. New narrative requests time out after 25 seconds and are cancelled when their evidence/scope changes or the screen closes.

If browser storage is blocked/full, download your narrative draft and existing vault/chapter exports before leaving. Imports are size-bounded. Existing raw vault recovery and preserved-save downloads remain available. Do not clear browser storage to resolve an AI problem.

The offline updater preserves older caches for active runs. Return home and use “Apply update & reload” when ready; it does not clear local progress. After a build, a previously open tab may still show the earlier offline shell until you apply its update.

## Validation

`npm test` runs all original checks plus `scripts/test-polish.cjs`: title variation/determinism, missing data, media path rejection/fallback, narrative validation, plain-text rendering, seven chapter banners, consent off, mobile/reduced-motion/focus rules and mocked API errors. `npm run build` typechecks and builds the offline shell. No real Gemini key is needed for tests.
