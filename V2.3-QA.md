## Practical limits

Default portraits are original role mascots; no character-specific licensed hero art is bundled. The original supplied splash is preserved but unused by default. Custom art requires a rights record and rebuild. AI factual grounding is enforced through bounded evidence and validated citation IDs, with prompt instructions against invented observations; narrative interpretations still require human review. Tests cannot certify all model wording.

New narratives use separate local save keys and separate export/import controls rather than modifying existing profile schemas. Narrative exports omit receipts by default. Existing vault backups include the original chapter snapshots and creative titles. Browser save portability still requires the same origin or profile export/import.

Vite reports a roughly 506 kB JavaScript chunk warning; the build succeeds. The seven chapters remain eagerly loaded as in the original app. This is a performance warning, not a functional build failure.
