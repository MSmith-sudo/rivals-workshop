# Rivals Workshop v2.5 — mobile setup

This release upgrades the supplied React beta. It keeps all seven chapters, question content, scoring rules, save keys, profile migrations, Gemini adapters, beta credentials, consent controls and rate limits. The ZIP contains source, the Node backend, local artwork, app icons and a prebuilt **closed-beta** `dist/`.

## For your Discord players

Players open the deployed HTTPS link, enter their individual beta username and token in the browser login prompt, and play. They do not install Node, VS Code or any development tools. In Discord, choose **Open in Browser** if the embedded browser does not show the login prompt or file picker. Android Chrome and iPhone Safari are the intended regular browsers; their actual-device checks remain in the QA checklist.

The bottom bar opens Home, Chapters, Companion, Vault and Team. Chapters autosave on the current browser. **Continue Assessment** restores the last chapter route and its saved stage. Question position in the focused scenario deck survives reloads within the tab; all actual answers use the existing durable chapter saves.

To save a named snapshot, open Vault → Open / migrate Player Vault → Save current chapters as new profile. Select a saved profile to rename, update, load or export it. Export the library before switching devices. Importing creates new profile IDs and resets team consent. Portrait uploads are separate browser settings, as in the original beta.

Companion opens a dedicated conversation screen. Choose a saved assessment, response mode and tone. Local reflection uses authored rules; it is explicitly labeled **no AI**. For Gemini, expand Privacy, select receipts, review the exact request and consent to each transmission. History saving is off by default. Optional writing assistance still lives beside chapter text fields, with preview, apply and undo.

Team Chemistry needs 2–6 profiles. Select each profile and record that player's explicit agreement before including it. Imports never imply consent. Removing consent excludes the player from the group. AI transmission requires separate request consent.

Final Judgment → Your integrated dossier offers four visual styles, print/PDF and a 1080×1440 PNG Discord card. Team Chemistry offers a team PNG and full JSON dossier. Share invokes the browser share sheet when supported; otherwise it downloads the PNG. Neither action posts automatically to Discord.

## Install on a phone

The Install app explanation describes Android Chrome's install/menu flow and Safari's Share → Add to Home Screen flow. The website works without installing. Browser support, Basic authentication behavior and install prompts must be confirmed on the deployed HTTPS origin.

The closed-beta service worker is intentionally network-only. It removes old workshop shell caches and does not intercept or persist authenticated pages, assets or API replies. Installation does **not** mean the private beta works offline. Existing browser-local profiles do not synchronize across devices, browsers, domains or necessarily into an installed Safari app. Gemini always requires a network connection. Export first.

## For the owner: local setup

Use Node 24 and run these from the extracted `rivals-workshop` folder:

```sh
npm ci --include=dev
npm run build:beta
npm test
npm run test:beta-security
npm run test:mobile
```

For an unprotected development preview, set `APP_ORIGIN=http://127.0.0.1:8787`, then run `npm start` and open that URL. For a protected local smoke test, use the procedure in RENDER-DEPLOY.md. `npm start` reads environment variables; `npm run server` additionally loads `.env.server`.

For Gemini, configure `AI_PROVIDER=gemini`, an account-supported `AI_MODEL`, and `GEMINI_API_KEY` on the server. Keep all secrets out of `VITE_*`, browser code and Git. No provider key or real tester credentials are bundled. The prebuilt beta starts with local reflection until you configure the server provider.

## Deploy the single HTTPS URL

Follow **RENDER-DEPLOY.md**. Keep the existing web-service Blueprint and one-instance limit. Build with `npm ci --include=dev && npm run build:beta`; start with `npm start`. Render supplies `PORT` and `RENDER_EXTERNAL_URL`. Production fails closed unless `BETA_USERS` contains generated-token hashes. Existing tester hashes can be reused unchanged; do not regenerate them merely to upgrade.

Do not deploy `dist/` alone as a public static site. The Node server must serve both frontend assets and `/api` from the same origin. Use the existing Render hostname to retain same-origin local saves. Changing the hostname requires exported backups. Before updating an old origin, have testers export their profiles; an earlier offline worker cannot be revoked remotely from an already disconnected browser.

Complete the actual-device and live-provider checks in V2.5-QA.md before announcing broad beta availability. This delivery does not create or modify a live Render service.
