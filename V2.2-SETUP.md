# Rivals Workshop 2.2 — upgrade and setup

This is an upgrade of the supplied V2.1 project. All seven chapters, Player Vault, chemistry, deterministic assessment and the Gemini adapter remain.

## Keep your existing data

1. In your running app, export your Player Vault/library and any active chapter draft backups before changing folders.
2. Extract this ZIP to a new folder. Keep your existing project and its `.env.server` as your rollback copy.
3. Copy your working `.env.server` into the new `rivals-workshop` folder yourself. The ZIP contains no credentials. If you already have a working Gemini model, keep that model setting.
4. Use the same browser and exact app address as before, including hostname and port. Browser saves belong to the address, not the folder. `localhost` and `127.0.0.1` have separate storage. Import your exported library if you intentionally change addresses.
5. If an offline update notice appears, finish the current run, export backups, return home and choose **Apply update & reload**. Do not clear browser data to update.

## Start the app

Use Node.js 22.9 or newer. In the extracted `rivals-workshop` folder:

```powershell
npm ci
npm test
npm run build
```

For development, keep `APP_ORIGIN=http://127.0.0.1:5173` in `.env.server`. Open two terminals in the project folder:

```powershell
# Terminal 1
npm run server
# Terminal 2
npm run dev
```

Open `http://127.0.0.1:5173`. Stop the old app processes first if they occupy the same ports.

For the built app, use `APP_ORIGIN=http://127.0.0.1:8787` in `.env.server`, run `npm run server`, and open `http://127.0.0.1:8787`. The included `dist` is already built; rebuilding is optional unless you change source. AI needs the backend; previewing the HTML alone does not connect it.

If you need fresh configuration, copy `env.example` to `.env.server`, then enter your key there:

```dotenv
AI_PROVIDER=gemini
AI_MODEL=gemini-2.5-flash-lite
GEMINI_API_KEY=YOUR_OWN_KEY
PORT=8787
APP_ORIGIN=http://127.0.0.1:5173
```

Restart the backend after changing configuration. Never put a key in a `VITE_` variable, browser storage, frontend code or an exported profile. Preserve your verified provider/model configuration when upgrading. Availability and quotas are controlled by your provider account.

## Use the additions

- **Companion:** Player Vault → select a profile → Companion. Hang out and Brainstorm join the existing tones. Generic chat can use zero chapter receipts. Review the question, selected evidence and history and consent before each request.
- **Writing help:** open **Optional AI writing help** directly under a chapter text field. Choose brainstorm, draft, expand, rewrite, clarify or revise; supply facts or tone instructions. Review the exact field/prompt payload, opt in, then request a preview. Compare Original and Proposed replacement. **Apply** changes that field; **Undo** restores it. A later manual edit disables Undo to protect the newer edit. Moving to a different field/stage cancels that field's request. AI text is a suggestion: check that it reflects your real experience.
- **Creative titles:** Chapter 7's integrated dossier and saved vault profiles have a title editor. Select evidence chapters, review and opt in, generate, then explicitly apply. Edit names yourself or restore stable local titles. Explanations and evidence receipts accompany generated titles. Changes in evidence flag saved titles as older; navigation alone does not invalidate them. Scores still use the original local rules.
- **Team titles:** select 2–6 consenting profiles in the chemistry studio. The team's title tool uses selected members' Chapter 1/3/4/5 receipts; generation requires a separate provider consent. Applied titles save locally for that membership/evidence snapshot and appear in the team dossier export.
- **Music:** paste an HTTPS YouTube video link in Chapter 6. Review the YouTube disclosure and opt in to **Fetch / refresh preview**. Real oEmbed title, uploader and thumbnail are saved separately from your entered song credits. No music plays automatically. Saved thumbnails require a click to load again in later views. Links from other platforms keep a safe external link and your own credits; unavailable metadata has a clear fallback. Refresh/remove preview is available. Changing a link clears the previous preview.
- **Exports:** vault profile/library JSON includes saved titles and song metadata in chapter snapshots. Chapter 7 includes creative titles; its written-answer checkbox controls raw title evidence and soundtrack details. Chapter 6 and the team studio retain their separate dossier exports. Inspect the exact export before sharing.

No third-party transmission consent is saved or imported. Google/provider data-use disclosures remain visible. YouTube is contacted only for an opted-in fetch or thumbnail load. The backend accepts YouTube IDs at a fixed endpoint, blocks redirects and never fetches arbitrary song URLs.

This backend binds to your computer's loopback interface and is intended for the existing local workflow. No public deployment was made.
