## Issues fixed during this upgrade

- Chapters anchor no longer jumps back to the page top after destination navigation.
- Chapter introductions shortened for phones; chapter content/controls stay focused on the current stage.
- Install help moved out of the fixed viewport layer so it cannot cover sticky studio tabs after scrolling.
- Lazy-loaded chapter styles are loaded before mobile overrides to keep responsive styling consistent.
- Discord card portraits align to the top to preserve character faces; unsupported/blocked native sharing falls back to download.
- Security tests updated from worker unregistration to the stronger relevant invariant: no authenticated cache/interception, with old-cache removal.

## Preservation

The original scoring, chapter state decoders, profile schemas, storage keys, migrations, recovery routines, Gemini permission/rate-limit code and beta credential guard are retained. A byte-comparison record is included as V2.5-PRESERVATION.json. UI changes wrap the existing chapter functions. No user saves or real credentials were copied into the delivery; browser testing used isolated synthetic profiles on a separate localhost port.

The app does not claim to observe real gameplay, predict rank, offer verified hero synergy or run Gemini offline. Browser profiles remain private and local by default; AI and team sharing remain explicit. Official portraits retain Marvel/NetEase ownership and per-image source URLs.

## Required release checks not performed here

1. **iPhone Safari:** HTTPS Basic login; all chapter destinations; keyboard open/close without hidden input; JSON file picker/export; native PNG share; Add to Home Screen; relaunch and profile availability. Test installed-mode authentication separately.
2. **Android Chrome:** Login, narrow/large font layouts, keyboard resizing, background/resume, JSON import/export, native share, install and relaunch.
3. **Discord iOS and Android in-app browser:** Login prompt behavior, links, keyboard, file chooser and downloads. If login or install/file APIs are unsupported, use Open in Browser; confirm the full-browser path before inviting testers.
4. **Live Gemini:** With a server-configured key, send nonsensitive sample data after payload review. Verify all six tones, writing preview/apply/undo, creative titles, history privacy/deletion and real quota failures. Mock success does not establish live model/account availability.
5. **Live Render:** Confirm HTTPS, single-origin APIs, unauthorized 401 for app/manifest/icons, tester revocation, no secrets in the browser bundle, correct model configuration and cold-start behavior. The public health endpoint intentionally exposes only health status.
6. **Accessibility on devices:** VoiceOver/TalkBack, 200% text, reduced motion and usable landscape/tablet behavior. Automated/visual checks here are not a full screen-reader audit.

The package is ready for the owner's hosted-device smoke test. It is not certified as tested on physical phones or a live provider. Installation never promises offline private-beta access or cross-device synchronization.
